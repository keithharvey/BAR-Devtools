Introduces the Keystone / Voussoir / Springer unit family (all three factions) and rewrites the tech-blocking gadget around them: tech levels are now driven entirely by living Keystone buildings (`tech_core_value`), thresholds scale per-player, and levels can **revert** when Keystones are destroyed. The old XP-accumulation path (`tech_points_gain`, `AllowCommand` interception) is removed — only factories/labs are tech-gated, not the units they build. A `ContextFactory.registerPolicyContextEnricher` callback publishes `ctx.ext.techBlocking` (level, thresholds, progression unlocks for unit/resource transfer) and wires `ctx.taxRate` and `ctx.unitSharingModes` to the current tech tier. Includes the `tech_core` mode preset, a `shield_downtime_mult` customparam for per-Keystone shield tuning, a healthbar fix that hides shield bars on switched-off units, a redesigned Tech Points HUD (Keystone count + milestone indicators + "one-more" pulse), cheaper T2 labs via `tech_blocking_defs.lua`, Keystone injection into T1 constructor menus, Legion mex rebalance under `tech_blocking`, and policy-level + integration tests.
